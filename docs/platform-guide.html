رفيقك اليومي للقرآن والذكر

منصة إسلامية تفاعلية تجمع القرآن الكريم، التلاوات، الأذكار، مواقيت الصلاة، القبلة، البث المباشر، ومتابعة الورد اليومي في تجربة واحدة.

1. نبذة عن المنصة

«صدقة جارية» منصة ويب موجهة للمستخدم المسلم الذي يريد الوصول إلى عباداته اليومية من مكان واحد. تم تصميمها باللغة العربية وباتجاه من اليمين إلى اليسار، مع دعم كامل للشاشات الصغيرة وأجهزة الكمبيوتر.

الفكرة الأساسية هي تحويل الاستخدام اليومي إلى عادة سهلة: يفتح المستخدم القرآن، يقرأ أو يستمع، يتابع أذكاره وورده، يعرف الصلاة القادمة، ويستطيع تحديد القبلة ومتابعة الحرمين.

الهدف: تقديم تجربة هادئة وعملية تساعد على الاستمرارية، مع حفظ تقدم المستخدم على جهازه دون الحاجة إلى حساب أو تسجيل دخول.

القيمة التي تقدمها

  • تجميع الأدوات الدينية اليومية في منصة واحدة.
  • تجربة عربية واضحة تعمل على الهاتف والكمبيوتر.
  • حفظ التقدم والإعدادات محليًا على جهاز المستخدم.
  • دعم التثبيت كتطبيق مستقل على الأجهزة المتوافقة.

2. أقسام المنصة ومميزاتها

القرآن الكريمقراءة السور بالنص العثماني، البحث باسم السورة أو رقمها، الانتقال السريع، حفظ آخر موضع، واختيار حجم الخط وطريقة العرض.
التلاواتمكتبة قراء، بحث وتصفية، دعم حفص وورش، مرتل ومجود، تشغيل وتحميل التلاوة، وتكرار السورة أو الآية.
الأذكارأذكار الصباح والمساء والنوم وبعد الصلاة وغيرها، مع عداد لكل ذكر، إعادة ضبط، نسخ ومشاركة.
الورد اليوميتحديد هدف يومي للصفحات، متابعة الإنجاز، عداد الاستمرارية، وربط الورد بأذكار الصباح والمساء.
مواقيت الصلاةجلب مواقيت الصلاة حسب الموقع، عرض الصلاة القادمة، عداد تنازلي، وتخزين مؤقت لبيانات اليوم.
بوصلة القبلةحساب اتجاه الكعبة والمسافة، اختيار مدينة، GPS، ودعم حساس اتجاه الهاتف عند توفره.
البث المباشرعرض بث قنوات الحرمين الرسمية عبر YouTube مع خيار فتح البث خارجيًا.
الإحصائيات والخططنشاط آخر سبعة أيام، خطة ختمة خلال 7 أو 15 أو 30 يومًا، وختمة جماعية قابلة للمشاركة.

3. تجربة المستخدم

التنقل

يوجد شريط تنقل رئيسي للشاشات الكبيرة وشريط تنقل سفلي سريع للموبايل. القسم النشط يظهر بوضوح، والانتقال يعيد المستخدم إلى بداية المحتوى.

المظهر

يدعم التطبيق الوضع الفاتح والداكن، مع حفظ اختيار المستخدم تلقائيًا. الألوان الأساسية تجمع الأخضر الهادئ مع لمسات ذهبية مناسبة لطبيعة المحتوى.

الصوت

المشغل الصوتي ثابت أسفل الصفحة، ويعرض السورة والقارئ والآية الحالية، مع التحكم في التشغيل والإيقاف، التقدم، مستوى الصوت، التكرار، التنزيل، ووضع القيادة.

الحفظ المحلي

يتم حفظ التفضيلات والعدادات والتقدم داخل localStorage. لا توجد قاعدة بيانات أو حسابات مستخدمين في النسخة الحالية.

ملاحظة خصوصية: الموقع الجغرافي لا يُطلب إلا عند ضغط المستخدم على زر تحديد الموقع، ولا يتم إرسال بيانات الحساب لأنه لا يوجد نظام تسجيل دخول.

4. البنية التقنية

العنصرالتقنية أو الملفالدور
واجهة التطبيقReact 18 + JSXبناء المكونات وإدارة الحالة والتفاعلات.
أداة البناءViteالتطوير المحلي وبناء نسخة الإنتاج.
التصميمTailwind CSS + CSSالتنسيق، الاستجابة، الوضع الداكن، والمكونات البصرية.
الأيقوناتLucide Reactأيقونات الواجهة والأزرار.
PWAvite-plugin-pwa + Workboxmanifest، Service Worker، والتخزين المؤقت.
اللغةJavaScript / JSXلغة المنطق والمكونات والخدمات.

هيكل الملفات الرئيسي

  • src/App.jsx: إدارة التطبيق والتنقل والحالة العامة.
  • src/data.js: أسماء السور والقراء والأذكار.
  • src/services/api.js: التكامل مع مصادر القرآن والقراء والتوقيتات.
  • src/components/: مكونات الأقسام والمشغل والإحصائيات.
  • src/index.css: التصميم العام والكلاسات المخصصة.
  • vite.config.js: إعداد Vite وPWA والتخزين المؤقت.

6. التشغيل والنشر

التشغيل المحلي

npm install
npm run dev

إنشاء نسخة الإنتاج

npm run build

معاينة نسخة الإنتاج

npm run preview

متطلبات النشر

  • استضافة ملفات static تدعم تطبيقات Vite.
  • تشغيل الموقع عبر HTTPS للاستفادة من GPS وPWA وبعض خصائص المتصفح.
  • ضبط متغيرات البيئة المطلوبة قبل البناء.
  • التأكد من صلاحية روابط البث ومصادر الصوت وقت النشر.
الحالة الفنية: تم اختبار نسخة التطوير ونسخة الإنتاج، ونجح البناء بدون أخطاء، كما تم اختبار الأقسام الرئيسية على مقاسات موبايل وتابلت وسطح مكتب.

7. حدود النسخة الحالية والتطوير المستقبلي

  • لا يوجد تسجيل دخول أو مزامنة بين الأجهزة.
  • التقدم محفوظ على الجهاز نفسه داخل التخزين المحلي.
  • بعض الخصائص مثل GPS والبوصلة تحتاج موافقة المستخدم وجهازًا يدعمها.
  • البث والتلاوات يعتمدان على توفر الخدمات الخارجية.
  • الختمة الجماعية في النسخة الحالية تعتمد على مشاركة الرمز والرابط، دون خادم مركزي لمزامنة تقدم المشاركين.

أفكار للتطوير

  • إضافة نظام حسابات ومزامنة سحابية.
  • إضافة تنبيهات مواقيت الصلاة والورد.
  • توسيع مكتبة الترجمات والتفاسير.
  • إضافة اختبارات آلية وقياس أداء مستمر.
  • إضافة لوحة تحكم لإدارة المحتوى والروابط.
